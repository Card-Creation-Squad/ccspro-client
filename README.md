# Überblick

Dieses Repository beinhaltet die Dateien für den modifizierten Edopro Client und den modifizierten Edopro Core. Die Lua-Scripte finden sich im anderen Repository.

# Installieren von Releases
## Core-Updates ausschalten
1) Öffnet die Datei `ProjectIgnis/config/configs.json`
2) Ändert das Attribut `"has_core"` auf `false`
## Neuestes Release herunterladen
1) Öffnet die Downloadseite `https://github.com/Card-Creation-Squad/ccspro-client/releases` und wählt den aktuellsten Release aus.
2) Ladet die Dateien `ocgcore.dll` und `ygoprodll.exe` herunter. Die `exe` Datei könnt ihr gerne umbenennen.
3) Platziert beide Dateien im Ordner `ProjectIgnis`.
